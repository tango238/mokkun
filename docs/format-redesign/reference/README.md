# 参照資料

デジタル庁デザインシステム（DADS）β版 v2 の公式サイトが配布する Markdown 版
（https://design.digital.go.jp/dads/resources/ の `dads-markdown-20261021.zip`、v2.18.2 時点）から、
UX に関わる利用指針を抽出したノート。原文の規則を1文ずつ要約し、数値は原文のまま。
`dads-markdown/` で始まるパスは zip 内のファイルを指す。

| ファイル | 内容 |
|---|---|
| dads-components-ux.md | コンポーネント別の用途・使わない場面・ルール・文言（39 コンポーネント） |
| dads-foundations-ux.md | レイアウト・余白・タイポグラフィ・リンク・色・アイコン・アクセシビリティ |

これらは `../04-yaml-authoring-rules.md` の出典として使う。規則の正本は DADS 公式サイト。
